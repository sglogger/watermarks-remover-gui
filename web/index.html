Nothing is stored. Uploads are held in memory for a few minutes and never written to disk. That is not the same as privacy: your content still leaves your device, travels to this server and is processed there. Don't put confidential or personal material through a service you do not run yourself — and if you do run it, remember that anyone with access to the machine has access to what passes through it.

All watermark detection and removal is performed by watermarks-remover, created by Guillaume Meyer and released under the MIT licence. This project is an independent web frontend for it and contains none of its code.

Detects invisible Unicode carriers, space and character lookalikes, and AI provenance metadata (C2PA, EXIF, XMP, document properties). Statistical token watermarks cannot be detected or removed here — they are only removable by rewriting the text. Audio and video are not supported.
